
# 👋 About Me

- **Backend:** Node.js, Express.js, NestJS, Python, Flask, FastAPI
- **Mobile:** React Native, Expo
- **Databases:** MongoDB, Firebase

- **AI/ML:** TensorFlow, TensorFlow.js, Computer Vision
